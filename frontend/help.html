How to use the review analysis workflow

Quick guide

  1. In Analyze Feedback, choose Paste reviews, Upload file, Analyze a link, or Demo dataset.
  2. For manual batches, separate each review with a blank line. CSV uploads need a review-text column. Jupyter Notebooks (.ipynb) can provide reviews in saved table outputs, Markdown text/tables, or literal review lists in code cells; notebook code is never executed.
  3. Review the validation counts, sentiment, aspects, emotions, ratings, and supporting review examples. Sentiment drivers show which mentioned aspects are most associated with positive and negative feedback; they are not proof of causation.
  4. Use the Dashboard page to inspect the latest aggregate overview. The Analytics page explains why model accuracy is not yet reported.

Link extraction limitations

Links are analyzed when a page exposes structured/marked review text or when the URL points directly to a CSV/JSON review export with a recognized review-text field. Product descriptions and titles are never treated as reviews. Sign-in-only or JavaScript-rendered content may not be accessible; use a source-provided export or authorized API rather than bypassing access controls.

Account and cloud history

Supabase Auth provides email/password accounts, and Supabase Postgres stores aggregate analysis history when configured in frontend/cloud-config.js. Only aggregate summaries are saved; uploaded files and individual review text are not sent to cloud storage. See the README for Supabase Auth, redirect URL, and row-level security setup.
